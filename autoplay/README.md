# 扫雷自动玩（外部机器人）

用**截图识别棋盘 + 虚拟鼠标点击**实时玩桌面上的扫雷。不需要游戏提供任何接口，
所以对经典扫雷和本项目自己写的 Java 版都能用。

它是 [扫雷 Minesweeper](../README.md) 的配套工具，住在仓库的 `autoplay/` 目录下。
有意思的是它的求解器（`solver.py`）就是本项目 `Solver.java` 的 Python 版 ——
一个直接读内存里的游戏模型，另一个得靠眼睛看屏幕。

## 用法

**双击 `扫雷自动玩.bat`** 就行。它会：

1. 自动找到桌面上正在运行的扫雷窗口
2. 报出识别到的盘面（几列几行、格子多大、多少雷、当前进度）
3. 实时认棋盘、算下一步、用鼠标点
4. **所有输出都实时打在 cmd 窗口里，不会往程序目录写任何文件**
5. 结束后显示战果，并提示「按回车键退出」

想要一个**不依赖 Python 的独立 exe**（可以拷到任何机器上双击运行）：

```powershell
powershell -ExecutionPolicy Bypass -File build_exe.ps1
# 产物：dist\MinesweeperAutoPlay.exe（约 27 MB，内置 Python + numpy + Pillow）
```

需要 Python 3 + `numpy` + `Pillow`。命令行用法：

```powershell
python autoplay.py                 # 接手当前局面，玩 1 局
python autoplay.py --games 3       # 连玩 3 局（局间自动点笑脸重开）
python autoplay.py --new           # 先点笑脸开一局新的
python autoplay.py --list          # 只列出识别到的扫雷窗口
python autoplay.py --verbose-board # 把每轮棋盘快照也打进日志
```

## 支持的目标

| 启动方式 | 进程名 | 说明 |
|---|---|---|
| 经典扫雷 | `saolei.exe` | 16px 格子 |
| 本项目 Java 版（安装/绿色版） | `Minesweeper.exe` | 20px 格子（默认 125% 缩放） |
| 本项目 Java 版（jar） | `java.exe` / `javaw.exe` | 会按窗口标题筛，不误抓别的 Java 程序 |

也可以吃自定义盘面 —— 实测过 9×9、16×16、30×16 以及 60×40/500 雷的超大棋盘。

## 它是怎么认棋盘的

1. **找窗口**：按进程名枚举顶层窗口，再用标题（含「扫雷 / mine / sweep」）确认。
2. **认网格**：未翻开格的左上角有 2px 白高光，整列/整行投影后是一串等距尖峰；
   取最长等距子序列就是网格。阈值取到峰值的 50%，避免被菜单栏、按钮高光那点
   零散白色带偏。已翻开的格子没有白边，但一定有深灰网格线，用它把被吞掉的
   列数补回来。
3. **认雷数**：左上角七段数码管。先用亮红像素的包围盒定位，再在「字符起点 +
   字符宽度」上搜索，把能识别成功的参数组合**加权投票**，避免命中错误参数
   （早期版本会把 `010` 读成 `131`）。
4. **认格子状态**：numpy 向量化，按像素判未翻开 / 旗子 / 问号 / 数字。
5. **踩雷判定**：踩中的格是红底 + 黑雷，所以要求「红占比高 **且** 有黑色」——
   只看红色会把数字 3 误判成爆炸。

## 玩的时候的注意点

* **首次点击**：Java 版是「首次点击后才生成雷区」，而且会跑「保证可解」验证、
  要好几秒。脚本会点一下并轮询等它展开，不会对着空棋盘瞎点。
* **重绘延迟**：一次 chord 会翻开二三十格，脚本用「连抓两张一致才采用」+ 按操作量
  等待的方式避免读到中间态（早期版本就是这么踩雷的）。
* **运气成分**：盘面密度越高越容易需要猜。60×40/500 雷那档实测能通关，但如果
  地图本身有必猜的死局，神仙也救不了 —— 想稳赢就用本项目的「保证可解」模式。

## 相关文件

```
autoplay.py     启动脚本（命令行界面 + 流程编排）
扫雷自动玩.bat  双击入口（找 Python、跑脚本、pause）
build_exe.ps1   打包成独立 exe
bot.py          核心循环：求解 → 点击，含踩雷归因与推理审计
layout.py       自动识别网格几何与数码管读数
board.py        向量化读盘
solver.py       求解器（约束传播 / 子集差分 / 分量枚举 + 全局雷数概率）
windows.py      窗口与对话框管理
mouse.py        Win32 鼠标模拟
test_solver.py / test_layouts.py / make_midgame.py / exp_chord.py   自测与实验脚本
```
